# Portfolio Pulse

A working prototype of AI portfolio insights for the smallcase Investments tab. It explains **how a multi-asset portfolio moved and what drove it**, for 1D, 1W, 1M and "since last visit".

**Live demo:** _link added after deploy_

> All companies, funds, people, prices and news items are fictional, generated by a seeded script. Index names are used only as labels. This is a concept, not affiliated with or endorsed by smallcase.

## The idea in one line

**Code computes, the LLM phrases, the validator checks.** The model never calculates a number or picks a cause.

If a draft fails a check, the AI is asked once more with the exact failed check. If one sentence still fails, only that sentence is removed. The investor gets the plain summary written by code only for a clear reason: a quiet period, no safe headline left, a required fact (such as the SIP) still missing, or no model answering by 8:30 AM.

## Run locally

Needs Node 18+. No dependencies to install.

```bash
npm run evals                       # 96/96 should pass
node scripts/dev-server.mjs         # http://localhost:3000, cached mode
LLM_PROVIDER=gemini LLM_API_KEY=your_key node scripts/dev-server.mjs   # live mode
```

## Deploy (Vercel, about 5 minutes)

1. Import this repo in Vercel. Framework preset: **Other**. No build command.
2. Add environment variables:
   - `LLM_PROVIDER`: `gemini`, `openai` or `anthropic`
   - `LLM_API_KEY`: your key (stays on the server)
   - `LLM_MODEL` (optional): defaults to `gemini-3.1-flash-lite`, `gpt-4.1-mini` or `claude-haiku-5-5`
   - `LLM_BACKUP_PROVIDER`, `LLM_BACKUP_API_KEY`, `LLM_BACKUP_MODEL` (optional): the backup writer, used if the primary errors or times out. The PM note pairs a Gemini Flash-Lite model with Claude Haiku 5.5
   - `MAX_LIVE_CALLS_PER_DAY` (optional, default 500)
3. Deploy. Visitors need nothing but the link.

Without a key the site still works end to end in cached mode.

## Safety of the public endpoint

- The server builds the facts packet itself from `persona` + `window`. Callers cannot send their own prompt, so the endpoint is not a free LLM proxy.
- 15 live calls per IP per 10 minutes, a daily cap, and a 10-minute result cache.
- These limits are in memory per serverless instance. Fine for a demo; production would use a shared store.

## Honest notes

- In production every card is built in the morning batch and the app reads it in under 0.3 s. Live mode here runs that same job on demand for one persona, so a card takes a second or two.
- Cached AI writer outputs (`data/cached_narratives.js`) and driver notes (`data/driver_notes.js`) were written during development by Claude, using the same prompts and facts packets. They pass the same validator. Live mode calls your configured model.
- The research agent pre-fetches its tool outputs so it works across providers without provider-specific tool calling. Production would let it call the tools directly, capped at 4 calls.
